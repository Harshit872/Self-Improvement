The big picture

4 Phases. 1 Career.

Each phase builds on the last. Do not skip phases. The sequence is intentional.

Phase 01 · Weeks 1–4
Java Foundations + SQL
~160–190 hrs · The most critical phase
Java syntax, OOP deeply, Collections, Generics, Streams, Exception handling, File I/O, Multithreading basics, Git, Maven, Linux CLI. NEW: SQL Foundations week added — SELECT, JOINs, transactions, and database design before you touch Spring Boot.
Phase 02 · Weeks 5–8
Spring Boot + REST APIs
~180–200 hrs · Core of your career
HTTP fundamentals, Spring Core, DI/IoC, Spring Boot, REST API design, MVC layers, DTOs, Bean Validation, exception handling, logging, config management, Swagger docs.
Phase 03 · Weeks 9–11
DB + Security
~140–160 hrs · Where it gets real
SQL deeply, PostgreSQL, database design, JPA/Hibernate, relationships, indexing, query optimization, Flyway migrations, Spring Security, JWT auth, RBAC authorization.
Phase 04 · Weeks 12–13
Production Engineering
~100–120 hrs · What separates good from great
Testing with JUnit 5 + Mockito, Redis caching, Docker + docker-compose, CI/CD with GitHub Actions, deployment to Railway/Render, capstone project, portfolio, career prep.
Daily study structure

Your Daily Routine

Morning · 2–3 hrs
Theory & Concepts
Read official docs or watch one focused video. Take notes by hand or in Notion. Understand the WHY, not just the HOW.
Afternoon · 2–3 hrs
Hands-on Coding
Implement what you learned. Type every line yourself. Break things. Read stack traces carefully. No copy-paste for first 4 weeks.
Evening · 1–2 hrs
Project Work
Apply today's concept to your running project. Commit to GitHub. Write a meaningful commit message. Push every session.
Night · 15 min
Reflect & Journal
Write 3 sentences: what you learned, what confused you, what to revisit tomorrow. This builds metacognition faster than anything else.

Week 04 SQL Foundations + PostgreSQL + Database Design ★ NEW — Added based on feedback ~36 hrs ↓
💡 Why this week exists: SQL is now placed before Spring Boot intentionally. Spring Data JPA generates SQL under the hood — if you don't understand SQL, you can't debug N+1 problems, write @Query annotations, read Hibernate logs, or design database schemas. 3–4 days of focused SQL here will save you weeks of confusion later.
Core SQL — must master all of this
Relational model: tables, rows, columns, keys DDL: CREATE TABLE, ALTER TABLE, DROP TABLE DML: INSERT, UPDATE, DELETE DQL: SELECT, WHERE, ORDER BY, LIMIT, OFFSET Data types: INT, VARCHAR, TEXT, BOOLEAN, TIMESTAMP, UUID Primary keys + foreign keys UNIQUE, NOT NULL, CHECK constraints INNER JOIN — the most important join LEFT JOIN (and when it differs from INNER) RIGHT JOIN + FULL OUTER JOIN (understand, use rarely) Aliases (AS) Aggregate functions: COUNT, SUM, AVG, MIN, MAX GROUP BY + HAVING Subqueries (WHERE x IN (SELECT ...)) Indexes: what they are, when to add them, when they hurt
Transactions + ACID — critical for Spring @Transactional
What is a transaction? BEGIN / COMMIT / ROLLBACK ACID: Atomicity, Consistency, Isolation, Durability Why transactions matter: partial failure scenario Isolation levels: READ COMMITTED, REPEATABLE READ, SERIALIZABLE Dirty reads, non-repeatable reads, phantom reads
Database design basics
One-to-many relationship design Many-to-many (junction table) 1NF, 2NF, 3NF normalization (understand, don't memorize) When to denormalize (and why) NULL vs empty string — important distinction
PostgreSQL setup + tooling
Install PostgreSQL locally psql CLI: connect, \l, \c, \dt, \d tablename DBeaver or TablePlus as GUI (pick one) Create your first database + schema
Practice tasks
SQLZoo.net — complete first 5 sections (free, interactive) LeetCode SQL Easy: 10 problems (175, 176, 182, 183, 196...) Design schema for: Users, Posts, Comments, Likes (social app) Write 5 JOIN queries against your own schema in psql Simulate a bank transfer using BEGIN/COMMIT/ROLLBACK
Mini project
E-Commerce Database Schema (Raw SQL, no ORM)
Design and create raw SQL schema for: users (id, email, name, created_at), products (id, name, price, stock, category_id), categories (id, name), orders (id, user_id, status, total, created_at), order_items (id, order_id, product_id, quantity, unit_price).

Write 10 queries: total revenue per category, top 5 customers by spend, products low in stock, orders in the last 30 days, average order value per user, etc. This becomes the exact schema you'll use in Week 9 when you connect JPA to it — so design it well.
❌ Skipping this week because "JPA handles SQL for me" — this is the #1 mistake. When your query runs 500ms in production and you enable show-sql: true, you'll need to read and understand what Hibernate generated. ❌ Not practicing JOINs until they're automatic — JOIN syntax trips up engineers in live coding interviews constantly. ❌ Ignoring transactions — @Transactional in Spring directly maps to what you learn here.

Internship & Career Strategy

The roadmap gets you the skills. This section gets you the job.

Critical mistakes to avoid
MISTAKE 01
Rushing into Spring Boot
Java fundamentals are not optional. Without them, Spring Boot becomes magic you can't debug. Fix: Complete all 3 weeks of Phase 1 properly before touching Spring.
MISTAKE 02
Copy-pasting code
You build muscle memory by typing, not reading. Fix: Type every line yourself for the first 4 weeks. No exceptions.
MISTAKE 03
Not committing to GitHub daily
Your green squares are your resume before you have work experience. Fix: Commit every single day, even 5 lines. Make it a ritual.
MISTAKE 04
Business logic in controllers
The most common junior mistake — and the first thing interviewers look for. Fix: Controllers handle HTTP only. All logic in the service layer.
MISTAKE 05
Skipping tests
No tests = no professional signal. Interviewers open your repo and look for tests. Fix: Write at least service-layer tests for every project from Week 11.
MISTAKE 06
Ignoring error messages
Stack traces are maps, not obstacles. Fix: Train yourself to read every stack trace fully before Googling. 80% of bugs are solved this way.
MISTAKE 07
Not understanding N+1 problem
This costs companies millions. Every backend interview asks it. Fix: Enable show-sql=true, watch your logs, identify it, fix it. Week 9.
MISTAKE 08
Hardcoding secrets in code
Your first PR rejection in industry will be for this. Fix: Every password, API key, DB URL goes in environment variables. .env in .gitignore. Always.
GitHub portfolio strategy

Your GitHub is Your Resume

01
Profile README
Create a profile README.md with: your name, current focus ("Building Java backend systems"), tech stack badges, top 3 projects with descriptions, and your learning goals. This is the first thing recruiters see.
02
Every Repo Needs
Clear README: what it is, tech stack badges, architecture diagram (draw.io), how to run locally, API endpoints table (or Swagger link), and screenshots/demo GIF. Repos without READMEs don't get read.
03
Commit Discipline
Small, meaningful commits: "Add JWT authentication filter" not "fix stuff". Use feature branches for every feature. Write PR descriptions. Even solo projects benefit from this discipline — it shows you work like a professional.
04
Pin Your Best 3
Pin: Library System (OOP), E-Commerce API (Spring + DB + Auth), and Job Board (Capstone). Unpin old tutorial repos. Recruiters see 6 pinned repos — make sure all 6 are things you're proud of.
05
Green Squares Daily
Commit every single day. Even a README update. Even 3 lines of a test. The contribution graph is visible on your profile. Recruiters notice a full year of green squares — it shows consistency and dedication.
06
Live Deployed APIs
Add the live API URL to your repo description. A recruiter who can hit your Swagger UI at a real URL is 3x more impressed than one reading about it. Deploy everything. Railway has a free tier.

Internship preparation timeline
1
Weeks 1–8: Build only. Don't prep interviews yet.
Your energy must go entirely into learning and building. Interview prep before you have skills is wasted anxiety. Focus. Build. Commit.
2
Weeks 9–10: Start LeetCode Easy/Medium
2–3 problems/day on arrays, strings, HashMaps, two-pointer. You don't need hard problems. Most internship interviews are Easy/Medium. Use NeetCode roadmap on YouTube.
3
Weeks 11–12: Practice verbal explanations
Practice answering: "Explain your project architecture." "How does JWT work?" "What is the N+1 problem?" "Write a SQL JOIN query." "What is Dependency Injection?" Say it out loud. Record yourself. Use Pramp for mock interviews.
4
After Week 13: Apply to 50+ internships simultaneously
LinkedIn Jobs (Easy Apply), Naukri, Internshala, company career pages, AngelList for startups. Write a personalized 3-sentence cover note mentioning their tech stack. Apply in batches of 10/day. Don't wait for one response before applying elsewhere.
5
Most asked backend interview topics
OOP principles with Java examples · Spring Dependency Injection · REST vs SOAP · SQL JOINs (write them live) · ACID + Transactions · JWT flow · @Transactional propagation · SOLID principles · HashMap internals · Time/Space complexity basics · What happens when you type a URL and press Enter
